# OWASP Top 10 Security Lab & Audit Reports 🛡️

Практический учебный проект по исследованию уязвимостей из списка **OWASP Top 10**. Цель проекта - это не просто запустить уязвимые приложения, но и глубоко разобраться в механике их работы на уровне бэкенда (на примере C# / ASP.NET Core), а также научиться составлять профессиональные отчеты по информационной безопасности.

## Структура проекта
Каждая папка содержит теоретический разбор, примеры уязвимого кода, шаги по эксплуатации и рекомендации по устранению (Remediation).
