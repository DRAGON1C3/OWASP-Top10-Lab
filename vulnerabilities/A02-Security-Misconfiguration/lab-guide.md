# Lab Guide: A02:2025 - Security Misconfiguration

Практическое воспроизведение кейса на локальном стенде.

## 1. Требования

- Docker
- Браузер с DevTools
- HTTP-прокси для перехвата и повторной отправки запросов (Burp Suite или аналог)

## 2. Запуск стенда

```bash
docker run --rm -p 3000:3000 bkimminich/juice-shop
```

Приложение доступно по адресу `http://localhost:3000`.

## 3. Учётные записи

| Роль | Логин | Пароль | Использование |
|---|---|---|---|
| Атакующий | `a@mail.ru` | `123123123` | Запросы к служебным эндпоинтам |
| Защищающийся | `def@mail.ru` | `123123123` | Не требуется: кейс проверяется анонимно |

## 4. Правила работы

1. Действия выполняются только против локального экземпляра.
2. Каждый шаг фиксируется: гипотеза, запрос, ответ, вывод.
3. Запросы сохраняются в прокси, чтобы потом воспроизводимо оформить PoC.
4. Скриншоты делаются сразу, а не по памяти.

## 8. Критерии завершённости кейса

1. Для каждого подтипа есть воспроизводимый PoC.
2. Объяснена корневая причина на уровне процесса деплоя, а не «забыли выключить».
3. Есть сравнение уязвимой и защищённой конфигурации в C#.
4. Рекомендации проверяемы: по каждому пункту понятно, как убедиться, что он выполнен.
